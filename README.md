 Projeto: Análise de Cancelamento de Clientes

Este projeto foi desenvolvido como parte da Jornada Python, com o objetivo de realizar uma análise completa sobre os motivos de cancelamento de clientes em uma empresa fictícia. Através da análise de dados com Python, buscamos entender padrões, identificar causas e propor soluções para reduzir a taxa de churn.

## 📊 Objetivo
Analisar uma base de dados de clientes e identificar quais fatores estão relacionados aos cancelamentos de serviços. A partir disso, aplicar técnicas de limpeza de dados, visualizações gráficas e métricas que permitam propor melhorias reais para o negócio.

## 🔧 Tecnologias e Ferramentas Utilizadas
- Python
- Pandas
- Plotly
- Jupyter Notebook (VSCode)
- Bibliotecas auxiliares: nbformat, matplotlib

## 🔎 Etapas do Projeto
1. Importação e visualização da base de dados
2. Limpeza e tratamento dos dados
3. Cálculo da taxa de cancelamento
4. Análise por tipo de contrato
5. Análise por tipo de assinatura
6. Visualizações gráficas com Plotly
7. Aplicação de filtros baseados em insights dos gráficos
8. Redução da taxa de cancelamento de **56,7% para 18,4%**

## 📈 Principais Resultados
- Identificação de que contratos mensais possuem alta taxa de cancelamento
- Clientes com mais de 5 ligações ao call center ou mais de 20 dias de atraso tendem a cancelar
- Aplicando os filtros certos, a taxa de churn foi reduzida para menos de 20%
- Possíveis melhorias estratégicas foram levantadas com base nos dados
